# El Comercial cowork proposal assets

These are proposal assets for Formosa.dev's recurring cowork concept. They are
not a confirmation of a partnership, venue, date or Luma registration.

The website and the current carousel source use only unchanged local images of
Formosa from `assets para contenido redes/Entornos/` and the preformatted
`fondos-presentacion/` files. They must not be replaced with generated scenes
or non-local imagery.

- `background-mastil-costanera.png` — real Formosa image used in the cowork proposal.
- `background-plaza-san-martin.png` — real Formosa image used in the second full-bleed parallax band.
